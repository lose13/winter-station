# Winter Station · 冬日复古车站雪景球

版本 **1.7.0**。可离线运行的 Three.js 微缩收藏品：胡桃木与黄铜底座、透明玻璃、复古站房、蒸汽机车、圣诞邮差和循环发生的车站故事。模型、纹理、音乐与音效均随项目交付，无在线 CDN、字体或模型服务依赖。

![室内微尘与炉火余烬的实际浏览器画面](screenshots/35-fireside-particles.jpg)

## 新增粒子氛围

- 暖光中有 144 颗缓慢漂浮的室内微尘，22 颗余烬在火炉玻璃门内升起。
- 礼物雪橇留下金色与少量冰蓝星屑，随飞行路径弯曲、闪烁并逐渐消散。
- 降落礼物带有细碎星光，落地时从礼盒外沿散开一圈，约两秒后消失。

全部为场景中的实时三维粒子，人物和建筑会正确遮挡它们；随昼夜调整明暗，随雪景球一起摇晃。新增特效默认开启，不需要单独操作。故事暂停时，微尘、炉火和雪橇等环境活动继续；投递落地只触发一次。

特效使用固定粒子池和不读取图片的程序着色器，没有新增贴图、音频、在线请求或阴影灯。追加 `?qa=1` 可显示运行数据和测试按钮；「落地星光」跳到着陆前两秒，便于复查。

## 走进候车室

点击底部 **「进站」** 或按 **I**，进入站房内部。新增 **候车室全景、窗边茶话、炉边阅读** 三个机位，可在上方菜单选择，也可按 **7 / 8 / 9** 直达。拖动水平环顾 360°，滚轮调整视野，**Esc /「返回雪景球」**回到进入前的球外视角。室内是固定观察点，未实现自由步行。

进出室内采用短暂淡入淡出；室内单独调整曝光和灯光，保留真实木地板、门、衣帽钩、双吊灯、人物、茶汽与炉火。竖屏使用单独构图。已有昼夜、音乐、环境音、故事暂停与隐藏 UI 均可继续使用。

## 微缩世界与故事


- **72 秒车站故事**：站长举旗、汽笛响起，火车沿弧轨轻轻前行，再缓缓回到站台。车轮与连杆联动，头灯、圣诞老人和烟汽发射位置跟随车身。
- **圣诞投递**：飞天麋鹿牵引礼物雪橇，一件包裹展开红白降落伞，落到轨道外侧；孩子走近抱起礼物、向圣诞老人挥手，再把它放到雪地。最多保留三件落地礼物。
- **有人的候车室**：两位室内旅客，一位端茶踱步并回应窗边访客，一位坐着翻书；增加铸铁火炉、火光变化、茶杯热气与窗缘霜花。保留九扇真实拱形窗洞与窗格投影。
- **共同的风**：松枝、围巾、信号旗、悬挂站牌和屋檐吹落的细雪响应同一阵风；站钟秒针转动。
- **车站小动物**：猫睡觉、伸懒腰、散步和舔爪；知更鸟在屋顶与站牌间飞行、停留和鸣叫。
- **点击回应**：圣诞老人转头挥手，麋鹿点头并响铃，窗内旅客走来问候，猫伸懒腰，知更鸟回应访客；点击列车可触发准备发车或鸣笛。实体遮挡会挡住点击，拖动不会误触。

故事默认循环播放。**P /「故事」**暂停或继续列车与投递情节；风、烟、小动物等环境活动继续。自动音效跟随**「环境」**开关；音乐独立控制，默认均关闭。手动 **W /「鸣笛」**可单独播放。

## 运行

### 单文件

打开根目录的 **Winter-Station-离线单文件.html**。引擎、样式、纹理生成逻辑及三段 MP3 均内嵌，可复制这一份文件使用。一般现代桌面浏览器可直接打开；本次自动化工具不允许 file://，所以实际验证使用了本地 HTTP，未把直接双击路径列为已实测。

### 本地预览

安装有 Node.js 18 或更高版本时，双击 **启动雪景球.cmd**，或在项目目录执行：

```powershell
node server.mjs --open
```

访问 http://127.0.0.1:5176 。服务器仅监听本机。若该端口已有本项目预览，直接访问现有页面即可。没有 Node.js 时，启动脚本会打开离线单文件。

### 修改与重新构建

预构建网页不需要安装依赖。修改源码后才需要：

```powershell
npm install
npm run build
npm test
```

构建同时更新 app.bundle.js 和离线单文件。重新生成 MP3 可运行 npm run audio，该制作工具需要系统 FFmpeg；播放交付音频不需要 FFmpeg。

## 画面与实现

约 192 万三角形的合批模型包含砖木站房、雪屋顶、冰柱、弧轨、轮辐与连杆、路灯、双面钟、长椅、行李、信号灯、站牌、足迹和分枝松树。六位室外人物、两位室内旅客、圣诞老人、麋鹿和小动物为可动关节模型。圣诞雪橇含七件礼盒、礼物袋、弯头滑橇和缰绳。

十三组实际投射光与体积光、九扇真实窗洞、十张聚光阴影贴图，另有两盏室内阴影吊灯；光束读取场景深度及灯光阴影，并在玻璃球内衰减。2,600 片雪花具有重力、阻尼、摇晃旋流、球壳约束与简化场景碰撞。煤烟、阀门白汽和站房白烟分别处理；列车移动后旧烟团留在经过的位置。

Three.js 0.170.0、esbuild 0.25.12。几何由源码生成，纹理由本地 Canvas 或着色器生成，无外部 GLB、OBJ 或贴图库依赖。音频为原创 C 大调 104 BPM 小圆舞曲、冬日站台环境音和汽笛；新铃声、鸟鸣与行车声由 Web Audio 实时合成。来源见 [ASSETS.md](ASSETS.md)。

## 测试与边界

本轮实际浏览器检查包含室内微尘与余烬、雪橇拖尾、礼物落地、摇晃、昼夜切换和窄屏构图。自动回归包含两轮投递、453,047 个可见特效位置、原有雪花边界和室内外机位。[截图图库](screenshots/index.html) 与 [测试记录](TEST-REPORT.md) 随项目附带。

火车是约 0.338 场景单位的短距离往返，现有轨道不是闭合环线。玻璃是实时薄壁光学近似，烟汽为粒子；积雪为雕刻几何，不会无限增厚。目标为 1080P 桌面独显，窄屏布局检查不代表低端手机性能保证。
